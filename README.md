Site de carros elétricos

# VOLTS MOTORS (React + Bootstrap)

# Estrutura
- `index.html` — carrega Bootstrap, React, Babel e o `js/app.js`
- `js/app.js` — aplicação React (todas as páginas e a lógica)
- `imagens/` — todas as imagens do site

# Páginas (rotas por hash)
`#/Home` · `#/tecnologia` · `#/modelos` · `#/sobre` · `#/contato` · `#/login` · `#/cadastro` · `#/senha` · `#/pedido`

# Como abrir
O `app.js` é compilado no navegador pelo Babel, então abra por um servidor Live Server no VSCode(não clicando duas vezes no arquivo):
- ou publique no GitHub Pages
